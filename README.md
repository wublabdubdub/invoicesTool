# 发票整理工具（invoices-tool）

本项目是一个基于 **Electron + React + TypeScript** 的桌面端发票整理应用，面向日常报销前的本地发票归档场景，支持 PDF / 图片发票管理、识别提取、分类筛选和按类别整理原始发票文件。

## 主要功能

- 批量导入 PDF / 图片发票（文件选择或文件夹扫描；图片支持 `jpg`、`jpeg`、`png`）
- 基于文件哈希（MD5）自动去重
- 导入后优先快速识别并回填字段（发票号、日期、销售方、税号、金额等）
- 支持航空运输电子客票行程单格式的飞机发票识别，归入“城市间交通”
- 导入/识别过程实时进度显示
- 支持打车行程单作为附件绑定到打车发票
- 批量导入时可自动识别打车行程单，并尝试按金额、日期、平台信息自动绑定
- 自动绑定失败时，提供候选发票复核面板，可直接手动补绑
- 支持手动“重新识别”（详情页按钮 + 列表高级操作）
- 手动编辑发票信息（日期、金额、类型、分类、项目标签、备注等）
- 按关键字、分类、项目、日期筛选
- 一键整理发票：在用户选定目录下重建 `整理发票` 文件夹，按当前分类创建子目录，并将发票复制为“商家_金额元”文件名

## 技术栈

- 桌面框架：Electron 33
- 前端：React 18 + Vite + TailwindCSS + Zustand
- 本地数据库：sql.js（SQLite）
- OCR：Python + PaddleOCR + PyMuPDF

## 环境要求

### Node.js

- 建议 Node.js `>= 20`
- npm `>= 10`

### Python（用于 OCR）

- Python `>= 3.9`
- 安装依赖：

```bash
pip install paddleocr paddlepaddle pymupdf opencv-python-headless
```

说明：
- 应用中可在“设置 -> OCR 设置”中填写 Python 路径并点击“检测”。
- 如果 Python 环境不可用，仍可导入文件，但识别会失败并在结果里统计失败数量。

## 本地开发

```bash
npm install
npm run dev
```

常用命令：

```bash
npm run build      # 构建前后端产物到 out/
npm run dist:mac   # 打包 macOS arm64 (dmg)
npm run dist:win   # 打包 Windows x64 (nsis exe)
```

## 使用流程

1. 导入发票 PDF 或图片（单个或批量）
2. 系统自动执行快速识别并实时显示进度
3. 批量导入时会额外识别打车行程单，并自动尝试绑定到对应打车发票
4. 如果存在未自动绑定的行程单，可在复核弹窗中直接补绑
5. 在右侧编辑区修正识别结果（如有需要可“重新识别”）
6. 设置项目标签、分类、备注等
7. 通过筛选面板查看需要整理的发票
8. 点击“整理发票”，选择保存目录，应用会重新生成 `整理发票` 文件夹

## 整理发票

- 整理时会在用户选择的父目录下固定创建 `整理发票` 子目录。
- 每次点击“整理发票”都会删除已有的 `整理发票` 子目录并重新生成。
- 发票会按照当前识别或手动修正后的分类分别放入子文件夹。
- 文件名格式为 `商家_金额元.ext`，例如 `深圳某公司_128.50元.pdf`。
- 如果商家或金额缺失，会使用 `未知商家` 或 `未知金额`。
- 如果同一目录下出现重名文件，会自动追加 `_2`、`_3`。
- PDF、JPG、JPEG、PNG 会保留原扩展名。

## 扫描说明

- 批量导入前会先扫描目录中的 PDF / 图片发票，默认使用 `fast` 模式。
- `fast` 模式对 PDF 采用“扫码 + 文本提取”判断，对图片采用“扫码 + 轻量识别”判断，适合大批量导入。
- 开发侧接口支持 `balanced` / `accurate` 模式，召回更高但更慢。
- 扫描结果会区分普通发票、打车行程单和非发票文件。
- 为保证批量导入速度，自动导入不会对无文本且无可靠二维码的扫描件立即执行深度 OCR；如字段缺失，可在详情页使用“重新识别”执行完整 OCR。

## 打车行程单

- 行程单不会作为独立金额参与统计，只作为打车发票的附件存在。
- 在发票详情中，只有 `打车` 分类会显示“行程单附件”区域。
- 整理发票时，主发票和已绑定行程单会放在同一个分类目录下。

## 本地数据存储

应用数据保存在 Electron `userData` 目录下：

- 数据库：`<userData>/data/invoices.sqlite`
- 发票文件：`<userData>/invoices/*.{pdf,jpg,jpeg,png}`
